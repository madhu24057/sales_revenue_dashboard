# Sales & Revenue Analysis Dashboard

## Project Structure
```
sales_dashboard_project/
│
├── sales_data.csv    # Dataset with sales and revenue records
├── app.py            # Main Streamlit dashboard script
└── README.md         # Instructions to run the app
```

## How to Run in VS Code

1. Open VS Code and open this unzipped folder (`File > Open Folder...`).
2. Open a terminal (`Ctrl + ~` or `Cmd + ~`) and install dependencies:
   ```bash
   pip install pandas streamlit plotly
   ```
3. Run the Streamlit app:
   ```bash
   streamlit run app.py
   ```
